## ⚠️ Технічна примітка: Проблема з верифікатором (EPERM)

Під час виконання цієї практичної роботи (а також попередніх робіт, пов'язаних із файловою системою), автоматичний CLI-верифікатор `eu-node-basics-workshop` стабільно видавав системну помилку Windows: 
`EPERM: operation not permitted, unlink '\\?\C:\Users\...\AppData\Local\Temp\...'`

**Причина:** 
Помилка виникає не через логіку написаного коду, а через агресивні механізми блокування файлів в ОС Windows. Верифікатор створює тимчасову папку для тестів, проганяє через неї стріми, а потім намагається миттєво її видалити. Оскільки Windows не завжди встигає миттєво звільнити файлові дескриптори після закриття потоку, верифікатор падає з помилкою доступу (`EPERM`), не зараховуючи правильне рішення.

**Рішення:**
Щоб довести працездатність коду, було прийнято рішення відмовитися від автоматичного верифікатора і провести ручне тестування всіх ендпоінтів за допомогою утиліти `curl`.
